# Holberton School - AirBnB Clone (HBnB)

This repository and project were made in the context of learning at Holberton School. The project goal was to learn about full-stack web development by building a clone of AirBnB, covering front-end, back-end, database storage, and API development.

## Description

HBnB is a complete web application that includes:
- A command interpreter for managing objects
- A website (front-end) for user interaction
- A database for persistent storage
- A RESTful API for programmatic access

## Repository Structure

- **part1**: Console and storage engine implementation
- **part2**: Web interface and API development
